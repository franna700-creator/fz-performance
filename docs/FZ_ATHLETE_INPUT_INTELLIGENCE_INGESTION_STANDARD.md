# FZ PERFORMANCE — ATHLETE INPUT & INTELLIGENCE INGESTION STANDARD

Authoritative project-level source: `FZ_ATHLETE_INPUT_INTELLIGENCE_INGESTION_STANDARD.md` in FZ Performance Project Sources.

This repository binding makes the release contract explicit:

- every athlete-originated message is an always-on potential ingestion trigger;
- natural athlete communication is translated into canonical structured meaning while preserving Athlete Voice and provenance;
- supported athlete-state evolution is persisted/reconciled as runtime data;
- downstream derivations and intelligence are invalidated/refreshed through the dependency graph;
- event additions/changes, targets, feedback, workout ingestion, Athlete Memory, capability evidence and recommendation recomputation using deployed logic are data evolution, not releases;
- Vercel deployment is required only when existing schema/registries/relationships/deployed logic cannot correctly represent the new information;
- persistence must never be claimed unless the relevant runtime operation actually occurred;
- infer, recover and research before asking the athlete to repeat or structure information.

The detailed Project Source remains the authoritative behavioural specification. This repository file exists to bind the software release and regression architecture to that instruction without duplicating the full Project Source text.
